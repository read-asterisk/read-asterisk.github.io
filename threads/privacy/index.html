Asterisk Threads プライバシーポリシー

このページは、note「＊からよむ」（以下「当アカウント」）が Threads に投稿するために使う自作のアプリ「Asterisk Threads」（以下「本アプリ」）の、個人情報の取り扱いについて説明するものです。

本アプリとは

本アプリは、当アカウントの運営者が、自分の Threads プロフィールに投稿を予約・公開し、自分の投稿の閲覧数などを確認するために使う、運営者専用の道具です。Meta の Threads API を利用しています。本アプリは一般の方に配布しておらず、運営者以外のアカウントで利用することはできません。

取得する情報

本アプリが取得するのは、運営者自身の Threads アカウントに関する次の情報だけです。

  • 運営者のプロフィールの基本情報（ユーザー ID・ユーザー名）
  • 運営者が本アプリから投稿した内容と、その投稿の閲覧数・いいね・返信数などの数値
  • 運営者の投稿に付いた返信（本アプリが返信を読む機能を使う場合）

運営者以外の方の個人情報を、本アプリが収集・保存することはありません。他の方の投稿を検索・収集する機能は使いません。

利用の目的

  • 当アカウントの投稿を予約・公開するため
  • 投稿の数値を確認し、発信の内容を見直すため

第三者への提供

取得した情報を第三者に提供・販売することはありません。情報は運営者の管理する機器にのみ保存します。

保存の期間

投稿の内容と数値の記録は、発信の見直しに必要な期間だけ保存し、不要になったものから削除します。

データの削除のご依頼

手順は データ削除のご依頼 のページをご覧ください。
